# Цифровизатор

**Frontend веб-сервиса для автоматизации генерации документов на основе шаблонов.**

Приложение предоставляет пользовательский интерфейс для работы с каталогом шаблонов, ввода и обработки данных, а также формирования и получения готовых документов.

## Запуск проекта

```bash
# Клонирование репозитория
git clone https://github.com/ItisDigitalizer/frontend.git

# Переход в директорию проекта
cd frontend

# Установка зависимостей
npm install

# Запуск приложения
npm run dev
```

## Обновление api-слоя

1. Добавить OpenAPI спецификацию (`.json` или `.yaml`) в корень проекта.
2. При необходимости обновить путь к спецификации в `openapi-ts.config.ts`.
3. Запустить генерацию api-клиента:

```bash
npm run openapi:generate
```
