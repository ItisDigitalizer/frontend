# Цифровизатор

**Frontend веб-сервиса для автоматизации генерации документов на основе шаблонов.**

Приложение предоставляет пользовательский интерфейс для работы с каталогом шаблонов, ввода и обработки данных, а также формирования и получения готовых документов.

## Запуск проекта

```bash
# Клонирование репозитория
git clone https://github.com/ItisDigitalizer/frontend.git

# Переход в директорию проекта
cd frontend

# Установка зависимостей
npm install

# Запуск приложения
npm run dev
